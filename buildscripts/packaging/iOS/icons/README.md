# CantoForge iPad icons

`CantoForge.png` is the 1024 × 1024 master icon, derived from the square logo
supplied by the maintainer. The 120, 152 and 167 pixel PNGs are resized versions
for the iPad application bundle. No part of the original MuseScore app icon
is used in these files.

The icons are bundled as loose PNG files so command-line builds do not need
a running simulator service to compile an asset catalog. The README displays
the same master image used by the application.
